CAM configuration

isolation-width: a band of width W only fully clears a gap G when 2·W ≥ G. A single pass leaves floating slivers between pads — the sliver predictor (check 9) computes the required width from the actual gap geometry and blocks “job ready” if the configured value leaves slivers near solderable pads. The autoleveller (al-*) is never emitted — it produces Mach3 G31.

Coordinate frame (FR5.3) — always zero-start=0, never zero-start=1

zero-start derives the origin from the job's bounding box, so changing isolation-width silently shifts EVERY output including the drill file (measured: dX −0.0234, dY +0.0234 between narrow and wide isolation). The fixed frame is the KiCad-page transform: x-offset = −MX, y-offset = MY (the kicad_regions.py constants; board 1: 4.3372, 3.2478), optionally plus a per-blank placement delta from the DRO-read blank corner. Verification check 12 proves the drill G-code is byte-identical across isolation widths on every full verify.
